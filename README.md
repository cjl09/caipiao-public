# 小彩日记

纯静态本地网站，包含每日骰子决定、10/20/30/50 元随机金额、排列3/排列5/福彩3D/快乐8随机选号记账，以及大乐透和双色球选号与组合金额计算。

## 运行

建议在本目录启动本地 HTTP 服务，这样浏览器能稳定保存 `localStorage` 记录：

```powershell
python -m http.server 4173
```

然后在浏览器打开 <http://localhost:4173>。

## GitHub Pages

此目录只包含可公开访问的网站文件。发布为 GitHub 仓库后，将 Pages 来源设为 `main` 分支的根目录即可部署；站点使用相对资源路径，适用于 `https://<用户名>.github.io/<仓库名>/`。

## 数据与规则

- 每日记录使用浏览器 `localStorage`，仅保存在这台设备和当前浏览器中。清理浏览器网站数据会删除记录；历史页可导出 CSV 备份。
- 页面不联网提交记录，也不会购买或出票。
- 数字彩随机页每生成一注就会自动记下号码和 ¥2 支出；快乐8可选择“选一”至“选十”，每次随机生成一注。大乐透和双色球的随机生成按钮也会将号码及对应注数/套餐金额计入当天记录。
- 每日总支出会合并骰子随机金额和数字彩随机票金额，记录表与 CSV 都会显示票面号码。
- 大乐透和双色球每注基本投注均按 2 元计。复式金额按组合数计算；大乐透支持双区、前区或后区随机胆拖组合。
- 单式和复式选号草稿自动保存在本机；有效号码可以另存到号码列表，并在之后载入。
- 复式随机选号可指定大乐透前/后区、双色球红/蓝球各选多少个号码，并显示组合注数和金额。
- 大乐透套餐为固定档位和固定结构：18、28、36、58、66、88 元。每套由指定数量的单式和复式组成，金额/格式固定，只需为每个组合选号。
- 双色球与大乐透的当前规则入口可在页面底部“号码规则来源”中打开。奖级、奖金、派奖和销售安排以官方当期信息为准。
- 随机选号是等概率随机，不会预测开奖结果；每个有效单式组合的概率相同。
